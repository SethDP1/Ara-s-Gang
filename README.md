### Descriptions of 2048 Game and Luhn Checksum Program
2048 Game
The 2048 game is a program that runs on a 4 x 4 'board' with powers of 2 making up tiles of the board. At the beginning, the board is filled with 0s and two 2s spawn, and the goal of the game is to continually combine numbers of the same value into larger numbers until you reach 2048 (and even higher for even better scores). This is accomplished by moving the tiles left, right, up, or down. When any of these controls are used, ALL tiles are shifted and this is where the strategy of the game comes in.
Luhn Checksum
The Luhn Checksum is a process that checks whether credit/debit card numbers are valid numbers when used to pay for things. This is a very important program in our modern society and a relativey easier thing to recreate.
